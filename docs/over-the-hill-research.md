# 《越过山丘 over the hill》完整调研 + 同款产品策划案

> 调研时间：2026-11-03。数据来源：Steam 商店 API（appid 2929250）、funselektor.com 官网、越过山丘社区 Wiki（overthehillhub.wiki）、3DM 与游民星空资料页。
> 标注：【官方】= 商店页/官网原文；【社区】= 粉丝 wiki 与攻略站整理；【推断】= 设计判断。

## 1. 一页结论

| 项目 | 结论 |
|---|---|
| 一句话 | 卖的不是“越野模拟”，而是“缓慢地做危险的事，就是一场冒险”（官网原话：to do something dangerous slowly is an adventure） |
| 本质 | 开放世界越野探索/远行，无剧情、无计时、无失败；单人 + 4 人线上合作 |
| 核心循环 | 发现目标 → 读路规划 → 被地形卡住 → 绞盘/木板/千斤顶自救 → 木屋/商人改装 → 拍照与发现换钱 → 揭示地图、开传送门 |
| 商业 | 愿望单 120 万；$24.99 / ¥86；发售后约 4,771 篇评测，商店综合【社区】为 Mixed |
| 口碑 | 好评：氛围、音乐、节奏、合作救援；差评：结构偏薄、目标少、区域跑完后缺少继续走的理由 |
| 三条结论 | ① 驾驶手感与脱困工具是生死线；② “无失败”是卖点也是风险，必须有内容厚度兜住；③ 美术与音乐是主产品，不是配套 |

商店页五个卖点：走别人不走的路（1–4 人）；值得发现的世界（木屋、观景点、地标、坠落陨石、传送门）；记录瞬间（相机 + 野生动物图鉴）；让车成为你的（改装、涂装、配件）；重要的是旅途（“这是驾驶游戏，不是竞速游戏”）。

## 3. 市场与口碑

- 发售前愿望单 120 万（中文媒体标题），说明“治愈向越野”确实存在市场空位。
- 发售后约 4,771 条评测，商店综合【社区】为 Mixed。
- 媒体口径一致（PC Gamer / Polygon / The Drive / Forbes / TraxionGG / HokiHoshi 等）：不是硬核模拟，是一段缓慢治愈的越野远行。

好评集中三点：氛围与可发呆的节奏（“电子游戏的冥想”）；音乐（Tatreal + Giacomo Giunchedi）；成就即调性（“见证一次日出”“关掉音乐开一段”）。

批评集中两点：结构偏薄（目标少、系统少，跑完区域后缺少理由）；对要清单、要传动深度的玩家不友好（无差速锁、无胎压、两档变速箱）。

## 4. 竞品坐标

| | 越过山丘 | SnowRunner | Expeditions | art of rally |
|---|---|---|---|---|
| 目标 | 探索、救援、拍照 | 合约与重载运输 | 科研任务、营地管理 | 赛段时间 |
| 失败压力 | 极低（只花时间 + 一个维修包） | 高（会丢货） | 中（会丢远征） | 高（赛段终止） |
| 联机 | 4 人线上，救援导向 | 4 人线上 | 4 人线上 | 以单人为主 |

空位：$25 价位 + 4 人低压合作 + 摄影/露营 + 复古 4x4 审美，目前只有它一家。对手不是做不出，是“不敢把失败惩罚拿掉”。

## 5. 体验拆解

设计命题：把“危险”降速，用耐心换掌控感。地形不出手，只等你读错；失败不惩罚你，只惩罚时间与维修包存量，于是撤退成为正常战术。

三层节奏：

| 层级 | 时长 | 内容 | 情绪 |
|---|---|---|---|
| 微观 | 10–90 秒 | 一次陷车、一次绞盘、一次过沟 | 紧张 → 释然 |
| 中观 | 20–60 分钟 | 一个目标链 + 回木屋改装 | 计划感、成长 |
| 宏观 | 3–10 小时 | 地点 → 区域 → 传送门 → 新地区 | 旅行感 |

## 6. 系统拆解

### 6.1 驾驶模型
全部 4x4 + 低速档/高速档两档；无差速锁、无胎压（官方排除）；手动变速箱只到两档。设计意图是把复杂度从“调车”移到“读路”：一条对的路线 + 一次到位的绞盘，胜过更快的引擎。悬挂、轮胎、涉水喉、防护是四条改装主线；外观只改观感，不改物理。

### 6.2 地形
泥地、湿地/沼泽、岩石、雪线、深水、陡坡、断面沟壑、木桥与车辙。抓地差异明显；深水会淹发动机。

### 6.3 车辆
4 个类别（按体量与用途，不带品牌）：轻小灵活 / 中型通用 / 重型牵引 / 涉水或长轴；1960–80 年代复古 4x4，约 20 台，3 台起始。类别性格差异必须大：轻车能上重车上不去的地方，重车能把轻车拖不出的车拽出来。

### 6.4 脱困工具（核心，不是配件）

| 工具 | 作用 | 规则 |
|---|---|---|
| 绞盘 | 拉出陷车/翻车 | 可挂树、车、目标点；自动/手动锚点；可串联两台车 |
| 木板 | 架桥跨断面 | 放置后消耗，数量有限 |
| 千斤顶 | 翻正四轮朝天 | 比绞盘慢，需相对平整地面 |
| 维修包 | 恢复总体血量 | 每趟限量 |
| 篝火 | 跳过恶劣天气/时段、休息 | 时间是资源 |
| 陨石雷达 | 指向最近坠落陨石 | 探索引导 |

### 6.5 世界结构
地区 → 地点（~4×4 km²，手工搭建）→ 传送门；木屋揭示周边地图、休息点、快速旅行点；商人在木屋附近；区域内用渡轮连接。首发两地区（加拿大含 The Valley / The Wetlands / The Mountains 工作名；阿尔及利亚），规划 6 个地点。

### 6.6 目标类型
车辆救援、小径挑战、观景点、木屋、自然地标、坠落陨石、传送门、野生动物摄影图鉴。

### 6.7 摄影与图鉴
野生动物图鉴是最温和的进度系统；风景照是社交货币与免费宣传素材。

### 6.8 经济与改装
货币来自发现、陨石、拍照；升级按系统分组（悬挂/引擎/防护/轮胎/涉水喉），【社区】二阶 25、三阶 50；外观另计。先买离地间隙，再买动力，防护最后。

### 6.9 天气昼夜
动态天气 + 昼夜改变抓地、能见度与路线可行性；风暴与黑夜会抹掉你规划好的路。天气工具 + 篝火 = 对时间的有限控制权。

### 6.10 合作
4 人线上、进度按玩家分别记录、单/多人存档互通、每区域单/多人都可玩、不强制组队；工具分工、第二台绞盘稳住拉力、第三人看线；无线电语音“在研究”；无本地分屏。

### 6.11 UI/UX
指路信息不超过一张地图 + 一个指南针；无倒计时、无强制收集；HUD 极简。

### 6.12 美术与音频
低多边形、干净克制的调色（art of rally 血脉）；音乐是产品的一部分；60–80 年代印刷海报/旅行杂志美学。

## 7. 它的问题 = 我们的机会

| 缺口 | 原因 | 我们的解法（不破坏无压力） |
|---|---|---|
| 区域跑完后没理由继续 | 目标一次性消耗、系统少 | 区域会变：天气周期改变可通行路线、季节路线重开、稀有动物/陨石刷新 |
| 目标同质 | 只有救援/观景/挑战 | 路线发现（自己开路并留标记）、救援车队、跟随野生动物迁徙等非战斗非计时目标 |
| 深度撑不住 | 故意简化传动 | 把深度放进读路工具：望远镜标记坡比、路面探测、绳索角度预演 |
| 后期钱无处花 | 升级树浅 | 车辆分工 + 工具槽扩展 + 涂装贴纸（纯外观） |
| 联机社交浅 | 无语音、无中途加入说明 | 无线电语音 + 中途加入 + 主机迁移 + 车队分工引导 |
| 差评“薄” | 内容体量有限 | 明信片日记、磁带收集、图鉴、成就叙事（低成本高感知） |

## 8. 表达边界（必读）

机制、循环、节奏、无压力设计不受版权保护，可以照着做；下列属于受保护的具体表达，照抄会踩雷：

| 可以复刻 | 不能照搬 |
|---|---|
| 核心循环、工具依赖、无失败设计 | 游戏名 over the hill / 《越过山丘》（商标） |
| 区域/地点/传送门的结构逻辑 | 具体地图布局、地名（Emerald Lake / The Valhallas / 加拿大三地点命名） |
| 车辆类别与分工 | 真实车型外观（车厂商标）、原车 1:1 建模 |
| 摄影图鉴、木屋揭图等系统 | 原 UI 视觉、原文案、原音乐、原成就名 |
| 低多边形风格方向 | 与 art of rally 完全一致的视觉识别 |

做法：机制层 1:1，表达层 100% 原创。

## 9. 我们的策划案

### 9.1 一页纸

| 项 | 内容 |
|---|---|
| 暂定名 | 《远山邮路》/《越岭》/ Slow Trail（避免与 over the hill 近似） |
| 平台 | PC 首发（Win/Linux），主机 12 个月后 |
| 价格 | ¥68–88 / $24.99；Supporter Pack + OST |
| 类型 | 开放世界越野探索 + 4 人线上合作 |
| 目标用户 | 25–40 岁，喜欢 art of rally / SnowRunner 但受不了压力、爱截图分享的慢玩玩家 |
| 卖点 | 无失败的越野远行；工具自救的满足感；复古 4x4 + 胶片旅行美学；4 人车队友情 |
| 时长 | 单局 30–60 分钟；主线 12–18 小时 |
| 差异化 | 会变化的荒野 + 旅行日记 + 读路工具 |

### 9.2 四条设计支柱
1. 慢即是险：危险来自地形与准备不足，不来自敌人与倒计时。
2. 工具胜过马力：每个障碍至少两种正解，且都依赖你带了什么。
3. 没有失败，只有代价：代价是时间、油耗与维修包存量。
4. 每一趟都值得拍一张照片：画面与音乐必须能独立成立。

### 9.3 核心循环

```text
[看地图选目标] → [读路规划：坡比/水深/断面] → [出发，遇阻]
      ↑                                              ↓
[回木屋改装/补给] ← [赚取：发现/陨石/拍照] ← [自救：绞盘/木板/千斤顶/维修包]
```

### 9.4 内容清单

| 项 | MVP（Demo） | 首发 1.0 |
|---|---|---|
| 地点 | 1 个（4×4 km²） | 4 个（1 地区） |
| 车辆 | 3 台（3 类别） | 8–10 台（4 类别） |
| 工具 | 绞盘/木板/千斤顶/维修包 | + 篝火/雷达/望远镜/绳索延长 |
| 目标 | 12 个 | 45 个 |
| 野生动物 | 5 种 | 16 种（含 3 稀有） |
| 天气 | 3 态 | 7 态 + 昼夜 |
| 音乐 | 4 首 | 14 首（含 6 盘可收集磁带） |
| 联机 | 2 人 | 4 人 |

### 9.5 驾驶与地形参数

| 参数 | 取值 |
|---|---|
| 车重 | 1,800–2,600 kg |
| 档位 | L：0–35 km/h；H：0–90 km/h |
| 抓地 | 沥青 1.0 / 干土 0.85 / 湿草 0.6 / 泥 0.55 / 雪 0.45 / 深水 0.3 |
| 涉水 | 基础 50 cm / 涉水喉 90 cm |
| 损伤 | 总血量 100；<50 挂挡迟滞、转向变沉 |
| 悬挂行程 | 25–40 cm |
| 物理 | 每轮 8 条射线 + 自定义悬挂/摩擦曲线 |

地形形变：不做全局可变形地形。用车辙贴花 + 局部细网格位移（单人近场），联机车辙由主机广播一次。

### 9.6 工具参数

| 工具 | 数值 | 交互 |
|---|---|---|
| 绞盘 | 绳长 10 m，拉力 ≈1.5× 车重，锚点角度容差 ±25° | 自动/手动锚；可串两台车 |
| 木板 | 长 4 m，限 2 块，用后消耗 | 需落在两个受力点 |
| 千斤顶 | 3 秒翻正，需平地 | 陡坡不可用 |
| 维修包 | 每个 +35 血，每趟 1–3 个 | 稀缺性制造远征张力 |
| 篝火 | 跳时至任意整点、存档 | 天气工具化 |

### 9.7 车辆与升级
4 类别：轻骑 / 通用 / 重载 / 涉水长轴。升级 3 阶：悬挂 25/50/100、引擎 25/50/100、轮胎 20/40/80、防护 25/50/100、涉水喉 30/60/120、绞盘 30/60/120。单区域可赚 ≈2,000–2,600，升级总花费 ≈1,800，逼玩家取舍。外观纯装饰。

### 9.8 世界结构
地区 → 地点（4×4 km²，手工）→ 传送门；木屋揭图半径 700 m + 休息 + 快速旅行；商人位于木屋附近；渡轮做地点内远距离移动；传送门不做万能解锁顺序。

### 9.9 目标与经济

| 目标 | 奖励 | 目的 |
|---|---|---|
| 观景点 | 25 | 奖励开到漂亮的地方 |
| 车辆救援 | 40 | 教绞盘与绳索 |
| 小径挑战（无计时，可选无损徽章） | 60–120 | 给硬核目标但不强迫 |
| 木屋 | 30 + 揭图 | 节奏锚点 |
| 坠落陨石 | 50 | 引导离开主路 |
| 首拍物种 | 20 | 低成本收集 |
| 传送门 | 80 | 章节推进 |

长线：周刷新陨石/稀有动物、区域天气周期、明信片日记（每趟自动生成可分享旅行卡）、磁带收集。

### 9.10 摄影与图鉴
焦距 24–200、简化曝光三档、4 种滤镜、相框与印章；物种卡记录时间/天气/地形偏好，鼓励不同条件下回访。

### 9.11 天气昼夜
7 态（晴/云/雨/雾/雪/风暴/极光），每态改变抓地与能见度 ≥25%；夜间依赖车灯与路线记忆；木屋提供天气预报道具。

### 9.12 合作
主机权威、4 人、20 Hz 状态同步；进度各自记录，检查点需全员到达；工具槽分工提示（不强制）；绞盘可挂队友车、可双绳稳定；支持中途加入/重连/主机迁移；语音先做按键语音 + 快捷沟通轮盘。

### 9.13 UI/UX
极简 HUD：档位、指针码表、车辆状态图标、工具轮盘、指南针条；无任务箭头（木屋可买路线笔记）；纸质地图全屏覆盖，带手绘标注与雾区。

### 9.14 美术与音频
车 600–1,500 三角面，2K 图集，生物群系 4 套调色板；胶片颗粒、轻微色偏、老照片边框；引擎 5 层叠加，风噪鸟鸣分层；1 位作曲 14 首，6 首通过磁带解锁。

### 9.15 失败、容错
翻车不等于失败（千斤顶/绞盘继续）；硬性资源只有维修包与时间（夜间更难）；永远允许撤退且不扣任何东西。
