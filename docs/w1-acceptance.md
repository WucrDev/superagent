## 已验证驾驶数据（Chrome headless + CDP）

- L 档直道：2 s 到 34.7 km/h；8° 坡/平台/下坡通过；30° 泥坡静止起步到坡顶平台（z=145.4, y=7.2）。
- H 档直道：73.2 km/h（测试场直道长度不足，未到 90）；带速度冲坡时可以靠惯性上 30°，但静止起步会滑下去。
- 手刹：30° 泥坡静止 2.5 s，z 131.94→131.86。
- 复位：回到起点，速度 0，档位回 L。
- 倒挡（W3 补充）：停稳后按住 S 约 0.45 s 接合 R，倒车限速约 12 km/h；行驶中 S 仍为刹车，Q/E 的 L/H 换挡不受影响（详见 [w3-acceptance](w3-acceptance.md)）。
- 相机：chase → free → cockpit → chase；座舱截图见 [`w1-cockpit.png`](images/w1-cockpit.png)；30° 爬坡截图见 [`w1-climb.png`](images/w1-climb.png)。
- 转向：D（+1）→ 车头朝世界 -X（追车画面右侧），A/D 与屏幕方向一致；有回归测试覆盖。
  - 同一输入（自由视角，W 1.5 s 后按住 D 1.8 s）：修复前 3839b13 位移 x +3.35 m、车头 +0.70 rad（世界 +X / 画面左）；修复后 c105878 位移 x -3.88 m、车头 -0.75 rad（世界 -X / 画面右）。

## 已知限制

- 35° 泥坡与 2 m 沟是 W3/W4 工具（绞盘/木板）的障碍，W1 车辆不保证直接通过。
- 水在 W1 只是视觉深度标记；涉水阻力、进水、材质摩擦曲线在 W2（见 [`docs/w2-acceptance.md`](w2-acceptance.md)）。
- 轮胎模型是 W1 近似（8 射线取最近接触 + 单点轮胎力），W2 才加材质摩擦、侧向阻力与打滑粒子。
- 座舱是 blockout；与测试车外模的三视图叠合、盲认在 W5。
- 主观项（10 分钟舒适度、座舱不穿模/不跳变、盲认车型）必须由人试玩打分；
  agent 只交付可玩基线与可复现的自测数据。
