# 绞盘交互详细设计（核心手感文档）

> 目标不是“按一个键把车拉出来”，而是让玩家在 **锚哪里、什么角度、拉多少** 三个判断上做决定。
> 判断做对 → 车动了 → 松一口气；判断做错 → 车不动/翻车/绳断 → 换方案。
> 这份文档只描述一个工具，因为它是整个游戏的心脏；其余工具按同样格式补。

## 1. 设计目标（验收时看这三条）

1. **可预测**：玩家看一眼地形，能大致判断“这个锚点行不行”。
2. **有代价**：选错不是无效，而是浪费时间/绳索/车身姿态。
3. **有画面**：成功的瞬间必须“好看好听”，能被截图和录屏。

## 2. 交互状态机

```
Idle ──按住绞盘键──▶ Aim ──确认──▶ Attach ──收绳──▶ Tension ──拉车──▶ Pull
                       │                │                  │
                       └─松开取消       └─断线/脱落 ◀──────┘（张力超限 1.2s）
                                                                 │
                                                          Release（松绳/收车）
```

| 状态 | 玩家输入 | 系统行为 |
|---|---|---|
| Aim | 左右摇杆/鼠标转视角；LB/RB 手动锚点 | 12 m 内锥角 60° 的候选锚点高亮，显示角度环 |
| Attach | 确认 | 挂钩飞行 0.3 s，命中锚点后绳子绷紧一格 |
| Tension | 收绳键 | 收绳 0.8–2.0 m/s，张力随距离缩短上升 |
| Pull | 油门（可选，自动挡辅助） | 车被拉向锚点，轮胎打滑/车身下沉 |
| Release | 松开按键 | 绳松，可再次收；离开车辆自动断开 |

**手动/自动两种模式**：默认自动（自动选评分最高锚点），按住“精瞄”进入手动。手动会奖励更快的脱困，但不禁止自动——自动只是慢一点。

## 3. 锚点判定

### 3.1 可挂类型

| 类型 | 是否可挂 | 结构强度 | 备注 |
|---|---|---|---|
| 树干/粗树 | 是 | 100 | 唯一稳定锚点 |
| 岩石（大） | 是 | 120 | 可能滚落（见失败态） |
| 细灌木/草 | 否 | — | 视觉误导，教学点 |
| 其他车辆 | 是 | 车辆质量 | 拖曳模式 |
| 木桩/电线杆 | 是 | 60 | 会断 |
| 地面锚（需铲子） | 后续版本 | 80 | 沙地/雪地无树时 |

### 3.2 评分公式（0–100，取最高者高亮）

```
score = 100
      - 2.0 × |期望方向与锚点方向夹角(度)|
      - 1.2 × max(0, 距离 - 4)
      - 3.0 × 高差惩罚(锚点高于车头 > 2m 时)
      + 结构强度修正(≤ ±15)
```

- 分数 < 25 时高亮变红并提示“角度不佳”，**但不禁止**——让玩家自己吃一次亏。
- 被岩壁阻挡的锚点直接不可选（射线遮挡检测）。

### 3.3 反例（必须实现的“读路教学”）

- 正前方 2 m、角度 80° 的树：能挂，但拉起来会把车头拽进坡里 → 玩家学会“别选太近的锚”。
- 河对岸的树：绳子跨水，拉的时候车会被横拖入水 → 玩家学会“先看水面宽度”。

## 4. 绳索模拟

| 项 | 方案 |
|---|---|
| 求解 | PBD 距离约束（16 段），迭代 4 次 |
| 弹性 | 刚度 0.6，阻尼 0.15，最大伸长 8% |
| 最大张力 | 1.5 × 车重 × 9.8（≈ 30 kN / 2 t 车） |
| 拖曳模式 | 挂车/队友时刚度 0.95、无弹性，直接带动物体 |
| 碰撞弯曲 | 绳索与地形做 1 次射线采样，最多 2 个弯折点（不做完整缠绕） |
| 断开 | 张力 > 上限持续 1.2 s → 断绳，车回弹 0.8 m，播放“啪”声 |

## 5. 拉力模型（紧张感的来源）

```
需求拉力 F = 地形摩擦阻力 + 坡度重力分量 + 障碍物顶推力
实际拉力   = clamp(玩家收绳产生的张力, 0, F_max)
车速 = 0  if 实际拉力 < 需求拉力
```

- 玩家看不到数字，只看到**车不动**。这就是“换锚点/换角度/先垫木板”的驱动力。
- 打滑时给轮胎粒子 + 地面拉痕，明确“力在，但抓不住”。
- 拉车时玩家可以踩油门辅助：油门贡献 20–35% 需求拉力，鼓励配合而非纯按绞盘。

## 6. 反馈（缺一不可）

**视觉**

- 绳从松到绷：曲线逐渐变直，颜色从浅灰到紧绷的白；
- 车头下沉 5–10 cm、悬挂压缩；
- 锚点（树）轻微摇晃，枝条抖动；
- 地面出现车辙与轮胎拉痕贴花（保留 60 s 后淡出）。

**音频（三层）**

- 卷扬机电机：随负载 3 段音高（空转/受力/过载）；
- 绳索：绷紧的高频“吱”声，张力越高越尖；
- 环境：鸟被惊飞、树枝断裂前的“咔”。

**触觉**：手柄 0.1–0.6 随张力线性震动；断绳瞬间 1.0 短脉冲。

**HUD**：可开关的“张力条 + 角度环”，默认关（沉浸优先，新手教程里打开）。

## 7. 失败态（全部可恢复，不惩罚）

| 失败 | 触发 | 结果 | 恢复 |
|---|---|---|---|
| 绳断 | 张力超限 1.2 s | 车回弹、绳掉在地上 | 重新挂 |
| 锚点脱落 | 强度 < 需求 1.5 s | 树断/石滚，车下滑 | 换锚点 |
| 侧翻 | 拉力方向偏 > 45° 且车速低 | 车侧翻/翻面 | 千斤顶（10 s） |
| 挂错（灌木） | 结构强度 = 0 | 挂钩脱落 + 提示音 | 立刻重选 |

## 8. 联机

- 绳索由**主机权威**模拟；客户端预测绳索可视，张力只做插值；
- 双绳：两台车同时拉时，张力叠加但方向按车重加权；不允许四根绳同挂一点（上限 2）；
- 队友互挂 = 拖曳模式，拖的人会掉速（防止“人力拖车”滥用）；
- 救援目标车（NPC）被拉动超过 20 m 即判完成，不要求拉到指定点。

## 10. 验收用例（10 条，做成清单逐条勾）

1. 平地上挂 8 m 外的树，收绳能把车拉出泥坑（≤6 s）。
2. 35° 泥坡：正对坡的锚点拉不上，偏 20° 的锚点能拉上——角度是有意义的。
3. 挂灌木：0.5 s 内脱落并给出可理解的提示，不是沉默失败。
4. 挂队友车：能拖动，拖的人掉速 30% 以上。
5. 河对岸锚点：拉车过程中车会向水侧偏（可预见、可避免）。
6. 张力超限：1.2 s 后断绳、回弹、可立刻重挂。
7. 树断：有明显的“断”的视听反馈与 0.5 s 的车身失控。
8. 手柄：张力有连续震动，断绳有单次强脉冲；键鼠也能完成全部操作。
9. 联机：两车同时拉同一目标，无穿模、无抖动、主机与客户端绳索位置差 < 0.3 m。
10. 录屏：一次“陷车 → 换锚 → 拉出”的 30 秒片段，发给非本组成员，8/10 能看懂发生了什么。

## 11. W3 五天迭代计划

| 天 | 交付 | 当天可玩 |
|---|---|---|
| 一 | 射线锚点检测 + 高亮 | 能看到候选锚点 |
| 二 | PBD 绳 + 收绳 | 能挂上并拉出 2 m |
| 三 | 自动/手动模式 + 角度环 | 能选锚、能感觉“角度不同结果不同” |
| 四 | 张力模型 + 视听反馈 | 拉不动/打滑/断绳三者可区分 |
| 五 | 失败态 + 两段测试地形 + 录屏 | 团队盲测打分（1–5），目标 ≥4 |
