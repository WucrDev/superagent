# ADR 0003：外测后移到 P2，P1 用内部/所有者验证

- 状态：已接受
- 日期：2026-11-05
- 决策人：项目所有者
- 相关：`docs/production-plan.md`、`docs/sprint-w1-w6.md`、issue #30/#32

## 背景

W6 原计划找 10 位外部目标用户测试 P1 灰盒原型，以“8/10 愿意再开一趟”作为 P1 门禁。项目所有者明确：外测是发给外部人员测的，**必须对成品做**；当前灰盒低模、占位美术，不适合也不方便发给外部人员，外测应往后放。

## 决策

- **P1 外测后移**：10 人外测（8/10 愿意再开）移到 **P2 垂直切片/预发布**，作为 P2 门禁的一部分；W6 不执行 10 人外测。
- **P1 门禁改为内部验证**：所有者自测 + 制作人独立验收；W6 #31 的两轮调参使用所有者自测反馈 + 内部指标。P1 是否进 P2 由所有者基于内部验证拍板，不再等 8/10 外测。
- #30 外测卡改为 P2 执行；#32 门禁记录该变更。

## 影响

- 项目可按 P1 → P2 推进；P1 的外部泛化未验证，风险由所有者接受。
- P2 的外测在更像成品的 build 上做；P2 门禁同时保留“30 分钟不出戏 + 4/5 愿意加愿望单”。
- W6 的验收从“外测 8/10”改为“所有者自测 + 制作人验收 + 两轮调参记录”。

## 风险

- 核心循环若有外部玩家不买账的问题，会在 P2 才暴露，可能导致返工/砍范围；缓解：所有者多轮自测、制作人独立验收、P2 早期小范围封闭测试。
- 没有外部数据支撑“愿意再开”的结论；P1 阶段不得对外宣称已验证外部留存。
