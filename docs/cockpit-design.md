# 座舱视角与内饰一致性设计（硬性要求）

> 地位：与 `docs/winch-design.md` 同级。本要求**不参与任何“砍范围”**，不接受“以后再加”。
> 适用范围：所有可驾驶车辆、所有阶段（W1 灰盒 → P3 量产）、单人与联机。
> 一句话：**每台车都能坐进驾驶位，且坐进去看到的内饰就是这台车。**

## 1. 三条硬性要求（缺一不可）

1. **必须有座舱视角**：每台可驾驶车辆都提供驾驶位座舱视角，与第三人称、自由视角并列；行驶、绞盘、拍照时都能随时切换。
2. **座舱必须与车型一致**：仪表台、方向盘、座椅、A 柱、门板、后视镜的布局与比例必须来自**同一车型的外模**；禁止多台车共用一套通用座舱，禁止换壳不换内饰，禁止内饰比外模宽/窄、坐姿穿车顶。
3. **验收必须有证据**：用同车型外模三视图叠合 + 座舱截图 + 盲认车型来判定，不靠“看起来差不多”。没有证据不算完成。

## 2. 座舱视角规格

| 项 | 要求 |
|---|---|
| 机位 | 驾驶位眼点；眼高、前后位置由车型数据驱动，不手工摆 |
| FOV | 60–90，默认 70，可与第三人称共用灵敏度设置 |
| 环视 | 左右各 90°、上下 45°；不做 360°（避免看到未做的内饰背面） |
| 切换 | 一键/手柄切换，0.2–0.3 s 平滑过渡；切换不改变车辆控制 |
| 动态 | 头部晃动/刹车点头可选，默认低强度；晕动选项可关 |
| HUD | 不遮挡仪表台关键信息；方向盘可隐藏（可选） |
| 性能 | 座舱视角相对第三人称掉帧 ≤10%；内饰单独 LOD/预算 |

## 3. “与车型一致”的定义

同一套车型数据同时驱动外模与内饰：

- 轴距、车宽、车高、坐姿高度、方向盘位置、仪表台宽度、A 柱角度；
- 每台车独立内饰套件；只有真正的通用件（如后视镜）可共享，且必须按车型适配；
- 外模与内饰使用同一套低模/材质规范；灰盒阶段用 blockout 定比例，量产阶段不得再改比例；
- 内饰必须包含可识别的车型特征（方向盘样式、仪表台布局、座椅颜色/缝线等），让玩家能认出是哪台车。

**反例（出现即不通过）**：所有车共用一套内饰；内饰与外模比例对不上；方向盘不在驾驶位正前方；坐姿穿车顶/引擎盖；从座舱能看到缺失的面。

## 4. 验收标准（逐条勾）

1. **三视图叠合**：座舱正/侧/顶视图与同车型外模三视图叠合，关键尺寸（仪表台宽、方向盘中心、眼点、坐姿高、A 柱角）误差 ≤5%。
2. **切换**：第三人称 ↔ 座舱 ↔ 自由视角连续切换 20 次，无穿模、无跳变、无控制丢失。
3. **盲认**：遮住车标与外观，只看座舱截图，团队 5 人中 ≥4 人能说出对应车型。
4. **多车型**：至少 2 台外形不同的车，座舱明显不同；把 A 车内饰套到 B 车会穿模/比例错误（证明不是通用件）。
5. **玩法**：座舱视角下能完成一次“陷车 → 绞盘 → 脱困”，HUD/角度环仍可读。
6. **拍照**：座舱机位能拍到方向盘 + 仪表台 + 前方路况，构图可用。
7. **性能**：座舱视角相对第三人称帧率下降 ≤10%，无新增卡顿。
8. **联机**：座舱视角下绳索/锚点/队友车可视，位置同步误差 ≤0.3 m（沿用绞盘验收）。

每个车型交付时附：三视图叠合图、座舱截图、切换录屏、帧率对比。证据进任务卡/PR。

> W1/W5 只有一台测试车，先执行第 1、2、5、6、7 条；盲认与多车型（第 3、4 条）在 P2/P3 有新车型时执行。

## 5. 分阶段落地（对应任务卡）

| 阶段 | 做到什么 | 任务卡 |
|---|---|---|
| W1 | 测试车座舱 blockout + 驾驶位相机；纯色材质，只验证比例、切换、不穿模 | #4 |
| W5 | 测试车座舱内饰 v0（仪表台/方向盘/座椅/门板/A 柱/后视镜）+ 座舱拍照；材质进入低模规范 | #19 |
| P2 | 低模资产管线：每台车必须含内饰；目标图增加座舱构图；相机模式含座舱机位 | 垂直切片 |
| P3 | 每新增一台车，内饰与外观共用同一车型数据；验收不过不许进内容生产 | 内容生产 |
| 联机 | 座舱视角不改变主机权威逻辑；内饰纯客户端表现 | P4 |

**W1 只做 blockout 不等于可以拖到后面**：座舱相机和比例必须在灰盒阶段就成立，否则后面所有车都要返工。

## 6. 不做什么（防止走偏）

- 不做第一人称步行/下车（本作不是步行模拟）；座舱只做驾驶位。
- 不做可交互内饰（车窗、收音机等），除非后续单独立项。
- 不用座舱视角替代第三人称；两种视角都必须可用。
- 不为座舱视角砍第三人称手感或绞盘可读性。

## 7. 与现有设计的关系

- 绞盘 `Aim` 状态允许在座舱视角下左右看，但锚点高亮/角度环仍按 `docs/winch-design.md` 的 HUD 规则显示；
- 座舱视角不是拍照模式专属：正常驾驶与绞盘全程可用，拍照模式只是多一个机位；
- 车辆物理、车型数据（轴距/质量/重心）沿用 W1 的车辆配置，内饰只读取，不改物理。
