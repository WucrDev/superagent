# superagent｜越野灰盒原型（W4 四件工具 build）

“一辆车、一段烂路、一根绞盘、四件工具”的越野灰盒原型。W1 目标：**能开**；W2 目标：**路有差别**；W3 目标：**绞盘脱困**；W4 目标：**四件工具齐了**。
当前版本是 three.js + Rapier 的浏览器可玩构建，不需要安装游戏引擎。

## 快速开始

1. 安装 **Node.js 22 LTS**（或 ≥ 22.12）与 npm。
2. 安装并初始化 Git LFS（美术资产需要）：

   ```bash
   brew install git-lfs   # macOS；其他平台见 https://git-lfs.com
   git lfs install
   ```

3. 安装依赖并启动：

   ```bash
   npm ci
   npm run dev     # 打开 http://127.0.0.1:5173/
   ```

## 操作

| 输入 | 动作 |
|---|---|
| WASD / 方向键 | 油门、刹车、转向 |
| S（停稳后继续按住） | 倒挡 R（≤12 km/h）；行驶中的 S 仍是刹车 |
| 手柄左摇杆 / RT / LT | 转向、油门、刹车 |
| Q / E 或 手柄 LB / RB | L 档 / H 档（0.3 s 动力中断；不影响倒挡接合） |
| C 或 手柄 Y | 切换第三人称 / 自由 / 座舱 |
| Space 或 手柄 A | 手刹（坡起不溜车） |
| R 或 手柄 Start | 复位到起点 |
| 1–4 或手柄 View + 方向 | 切换绞盘 / 木板 / 千斤顶 / 维修包（按住 T 或手柄 View 开轮盘） |
| G（当前工具） | 绞盘挂钩/松绳；木板架桥；维修包修理（停稳按住 2 s） |
| J 或 手柄十字下 | 千斤顶翻正（侧翻后按住 3 s，坡度需 < 15°） |
| Backspace | 丢下当前木板/维修包 |
| 鼠标右键拖动 | 自由 / 座舱视角环视 |
| 滚轮 | 相机距离 |
| Esc | 手柄死区、转向灵敏度、FOV 设置 |

## W1 已实现（#1–#5）

- **工程骨架**（#1 / issue #7）：Vite + TypeScript，npm 锁版本，60 Hz 固定步长，Git LFS。
- **射线悬挂车辆**（#2 / issue #8）：每轮 8 条射线、弹簧-阻尼、上下限位；车身质量/重心可配。
- **两档变速箱**（#3 / issue #9）：L 0–35 km/h、H 0–90 km/h，换档 0.3 s 动力中断 + 合成换档音；手刹坡起；停稳后按住 S 进入倒挡 R（≤12 km/h），松开 S 回 L/H。
- **相机与输入**（#4 / issue #10）：第三人称跟随、自由环视、座舱 blockout（仪表台/方向盘/座椅/A 柱/门板/后视镜），死区与灵敏度设置。
- **白盒测试场**（#5 / issue #11）：800×800 m，包含 8° 缓坡、40 cm 浅水、岩石堆、30°/35° 泥坡、2 m 沟、80 cm 深水、3 个绞盘锚点。
- HUD：速度、档位、相机模式、输入设备；合成引擎音。

验收自测与已知限制见 [`docs/w1-acceptance.md`](docs/w1-acceptance.md)。

## W2 已实现（#6–#7 / issue #12–#13）

- **四种路面材质与抓地曲线**（#6 / issue #12）：泥 / 岩 / 雪 / 深水；每轮按接触 collider 查 `Surface`，摩擦随滑移速度衰减，侧向力与滚动阻力按材质变化。测试场新增 4 条材质车道和干土 / 湿泥同一 30° 坡。
- **材质手感调优**（W2 试玩反馈）：车道改为从 z=54 开始（48 m），从车道起点静止起步就在对应材质上；泥 / 雪 / 岩参数拉开，起步、制动、滑行与转向的差异由 `surface feel` 单测守护。
- **坡度、涉水与打滑**（#7 / issue #13）：`slopeDeg` 坡度查询；80 cm 深水触发进水（动力 -40%，10 s 恢复），40 cm 浅水不触发；打滑雪屑/泥屑粒子、轮胎拉痕、深水白烟与水花。

验收自测与已知限制见 [`docs/w2-acceptance.md`](docs/w2-acceptance.md)。

## W3 已实现（#16–#20 / issue #16–#20）

- **绞盘**：12 m / 60° 自动选锚、X 手动换锚、V 回自动；G 直接挂钩/松绳，按住 F 收绳。锚点、16 段 PBD 绳索、张力与断绳/锚点脱落/灌木滑脱/侧翻失败态按 `docs/winch-design.md` 实现。
- **脱困场景**：出生点练习锚点、35° 湿泥坡、跨水锚点、可断木桩与可滚岩石。
- **反馈**：张力条（H）、角度环、绳色/车身受力、轮胎拉痕与打滑粒子、电机三段音与震动。

验收自测见 [`docs/w3-acceptance.md`](docs/w3-acceptance.md)。

## W4 已实现（#21–#24 / issue #21–#24）

- **木板架桥**（#21）：4 m 板、两端受力点检测、放置消耗；2 m 沟可过；斜放会滑落并提示；过桥时板面轻微下沉与吱呀声。
- **千斤顶**（#22）：侧翻后按住 J/手柄十字下 3 s 翻正，需坡度 < 15°；陡坡上给出理由而不是静默失败；液压声与车身抬正动画。
- **维修包与车况**（#23）：车况 100；撞击掉血，< 50 时动力/转向衰减；停稳按住 G 修理 2 s，每包 +35；每趟起始 1 包、路上 2 个补给箱。
- **工具轮盘与库存**（#24）：4 槽 + 数量；1–4 直选、按住 T / 手柄 View 开轮盘；补给箱自动拾取、Backspace 丢弃、倒车可捡回；手柄十字/左摇杆选槽。

验收自测、Before/After 与已知限制见 [`docs/w4-acceptance.md`](docs/w4-acceptance.md)。
